🎮 바로 게임 시작
설치할 수 있는 브라우저에서는 설치 확인창이 표시됩니다. 지원하지 않는 기기에서는 아래 안내에 따라 홈 화면에 추가하세요.

설치 버튼이 바로 작동하지 않나요?

  1. Android Chrome: 브라우저 오른쪽 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치
  2. iPhone Safari: 공유 버튼 → 홈 화면에 추가
  3. PC Chrome/Edge: 주소창의 설치 아이콘 또는 브라우저 메뉴에서 앱 설치

설치 여부는 기기와 브라우저가 결정하며, 이용자의 확인 없이 자동 설치되지 않습니다. 아이콘은 온라인 Blogger 게임을 엽니다.
